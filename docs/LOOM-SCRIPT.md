# 60-Second Loom Demo Script

**Goal:** Show freelancer pain → 10-second fix → alert + status page.

## 0:00–0:08 — Hook
> "I manage client WordPress sites. I used to learn about downtime from angry emails."

Show empty email inbox or a fake "site is down" message (optional).

## 0:08–0:20 — Add a site
1. Open https://site-pulse-brown.vercel.app/dashboard
2. Click **+ Add site**
3. Type client name + URL → Save
4. Say: "Ten seconds. No agent on their server."

## 0:20–0:35 — Dashboard + status page
1. Point at the site card (uptime + SSL days left)
2. Click **Status page** → show shareable public URL
3. Say: "Send this link to clients so they see green, not panic."

## 0:35–0:50 — Alerts (optional if configured)
> "If it goes down or SSL expires in 14 days, I get Telegram before the client notices."

Show Telegram alert screenshot if you have one; otherwise skip.

## 0:50–1:00 — CTA
> "Self-host free with Docker — GitHub link in description. Or use managed for $9/month."

**End card text:**
- GitHub: github.com/tangyumeng/site-pulse
- Live demo: site-pulse-brown.vercel.app

## Recording tips
- 1280×720, dark mode matches the UI
- Keep mouse movement slow; pause 2s on status page
- Upload to Loom → paste link in Reddit post as comment
